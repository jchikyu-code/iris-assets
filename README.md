# iris-assets

イリス管財の社内ツール（Google Apps Script ウェブアプリ）で使う公開画像の置き場です。
GAS の `HtmlOutput.setFaviconUrl()` は公開URLの画像しか使えないため、ここに置いています。

| ファイル | 用途 | URL |
|---|---|---|
| `favicons/iris.png` | 会社ロゴのマーク（128×128・透明背景）。社内ツールポータルのファビコン | https://raw.githubusercontent.com/jchikyu-code/iris-assets/main/favicons/iris.png |

社外秘の情報は置かないこと（このリポジトリは誰でも見られます）。
